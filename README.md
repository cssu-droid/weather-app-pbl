# 🌤️ 気圧・湿度チェッカー (weather-app-pbl)

PBL（課題解決型学習）の一環として開発している、気象病対策のための気圧・湿度予報アプリケーションです。
スマートフォン表示への完全対応と、外部API（OpenWeatherMap）とのリアルタイム連携を網羅しています。

## 1. アプリ概要と動く機能
本アプリは、日々の開発成果をリアルタイムに反映し、以下の要件をすべて満たしています。

- [x] **現在の天気・気温・気圧・湿度の表示（3秒以内）**
  - 入力された市区町村のリアルタイムな気象データを取得して4連のカード形式で表示します。（「水分」から「湿度」へUIを最適化済み）
- [x] **今後24時間の気圧変化グラフ（Plotlyによる折れ線グラフ）**
  - 今後の気圧の波形を視覚的に分かりやすい折れ線グラフで描画します。都市名（例: `okayama`）に完全に連動します。
- [x] **適切なエラー画面の表示（堅牢性）**
  - 未入力や、存在しないデタラメな地名が入力された際に、アプリがクラッシュせず「場所が見つかりませんでした」等のメッセージを出し、次の行動を促す親切な画面を表示します。
- [x] **UI/UX：スマートフォン最適化（レスポンシブ表示）**
  - スマホ表示モードでも、グラフやカードが画面幅からはみ出さずに綺麗に自動で折りたたまれて収まります。

## 2. アプリの起動方法
事前に必要なライブラリ（`streamlit`, `requests`, `pandas`, `plotly`）をインストールした状態で、VS Codeのターミナルにて以下のコマンドを実行してください。

```bash
streamlit run appp.py
