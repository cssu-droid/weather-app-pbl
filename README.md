# 🌤️ 気圧チェッカー (気象病対策アプリ)

PBL（課題解決型学習）の一環として開発している、気象病対策のための気圧予報・チェックアプリです。
スマートフォン表示への完全対応と、外部API（OpenWeatherMap）とのリアルタイム連携を検証しています。

## 📅 現在の進捗・動く機能

毎週まとめて更新するのではなく、日々の開発成果をリアルタイムに反映しています。

- [x] **要件1：現在の天気・気温・気圧の表示（3秒以内）**
  - 入力された市区町村のリアルタイムな気象データを取得して3画面のカード形式で表示します。
- [x] **要件2：今後24時間の気圧変化グラフ（Plotlyによる折れ線グラフ）**
  - 今後の気圧の波形を視覚的に分かりやすい折れ線グラフで描画します。
- [x] **要件3：適切なエラー画面の表示**
  - 存在しないデタラメな地名や、国コードの組み合わせ（例: `xyz,us,jp,uk`）が入力された際に、アプリがクラッシュせず「場所が見つかりませんでした」と次の行動を促す親切な画面を表示します。
- [x] **UI/UX：スマートフォン最適化（レスポンシブ表示）**
  - `F12` のデベロッパーツール（スマホ表示モード）でも、グラフやカードが画面幅からはみ出さずに綺麗に収まります。
- [ ] **気象データ連携の完全反映（APIキーのアクティベート待ち）**
  - コードは本番APIと通信する状態に切り替え完了していますが、新規発行した無料APIキーが世界サーバーに同期されるまで、一部の地域（`yokohama` と `okayama` など）で同じサンプルデータが返ってくる現象を確認済み。キーが有効化され次第、自動的に完全な個別リアルタイムデータへ切り替わります。

## 🛠️ 起動方法

事前に必要なライブラリ（`streamlit`, `requests`, `pandas`, `plotly`）をインストールした状態で、以下のコマンドを実行してください。

```bash
streamlit run app.py
